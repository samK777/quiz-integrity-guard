# Quiz Integrity Guard 🛡️

A Chrome extension + integrated portal designed to detect tab switching during online assessments and automate evaluation based on intelligent rules.

## 🚀 Features
- Detects tab switching in real-time during quizzes
- Alerts users on suspicious activity
- Helps maintain integrity in online exams

## 🧠 Ongoing Development
Currently expanding this project into a **complete integrated quiz platform** with:

- 📊 Teacher Dashboard  
  - Create and manage quizzes  
  - Add questions using structured templates  

- ⏱️ Smart Timer Integration  
  - Track time spent per question  
  - Custom time limits set by teachers  

- 🤖 Automated Evaluation System  
  - Marks based on correct/incorrect answers  
  - Adaptive scoring using teacher-defined rubric  
  - Bonus scoring for solving difficult questions quickly  

- 📈 Performance Analytics  
  - Student-wise insights  
  - Attempt behavior tracking  

## 🛠️ Tech Stack
- JavaScript  
- Chrome Extension APIs  
- HTML, CSS  
- (Planned) Firebase / Backend Integration  

## 📌 How it works
The extension tracks tab focus changes using browser event listeners and flags suspicious behavior.  
The upcoming portal will integrate quiz creation, monitoring, and intelligent evaluation into a single system.

## 🔧 Installation
1. Clone this repo  
2. Go to Chrome → Extensions  
3. Enable Developer Mode  
4. Click "Load Unpacked"  
5. Select project folder
